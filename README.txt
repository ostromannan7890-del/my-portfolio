# Personal Portfolio Website

## Files
- `index.html` — main website
- `style.css` — design and responsive layout
- `script.js` — mobile menu
- `profile.jpg` — add your own profile picture with this exact filename

## Before submission
1. Open `index.html`.
2. Replace `Abdul Mannan` if needed.
3. Replace `your-email@example.com` with your real email.
4. Replace the LinkedIn, GitHub and Instagram URLs with your actual profile URLs.
5. Put your profile picture in this folder and name it `profile.jpg`.
6. Open `index.html` in a browser and test every link.
7. Upload the folder to GitHub and deploy it on Vercel/Netlify, or use GitHub Pages.
